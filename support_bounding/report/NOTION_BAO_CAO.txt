# Overview Task
-------------------------------------------------------------------------------------------

Task: xây LUỒNG (pipeline) tự động vẽ bounding box cho món ăn trong ảnh, để gán nhãn dataset FoodAI của nhóm.
  1. Khảo sát các model auto bounding box (survey.md): Grounding DINO, OWLv2, YOLO-World, Florence-2, SAM 2/3, autodistill.
  2. So sánh 3 model trên UECFOOD-256 có box thật → chọn Grounding DINO.
  3. Tự gán nhãn ảnh dạng <tên_món>/*.jpg: xuất nhãn YOLO, classes.txt, data.yaml, ảnh đã vẽ box, report.csv / failed.csv
     (ảnh cần sửa tay), và cắt từng box thành ảnh riêng.
  4. Khi có dataset thật: chỉ cần đổi tên dataset trên Kaggle là chạy.

Kết quả chính:
  - Ảnh 1 món: box tốt (tìm được 90% món, box món chính đúng ~95% khi chấm tay trên Food-101).
  - Ảnh khay nhiều món: còn yếu (tìm được 68% món, chọn đúng món chính 38%).
  - Box ôm phần thức ăn, không ôm cả đĩa (box nhỏ hơn box thật UEC ~20%, vì box thật UEC ôm cả bát).


# Kiến trúc thiết kế mô hình
-------------------------------------------------------------------------------------------
(Tạo page riêng, dán nội dung dưới đây rồi copy link vào đây)

Ảnh món ăn (RGB, xoay theo EXIF)               Câu chữ "food."
  │                                              │
  ▼                                              ▼
Swin-B (backbone ảnh)                          BERT-base (backbone chữ)
  └──────────────┬───────────────────────────────┘
                 ▼
Feature Enhancer: self-attention + cross-attention ảnh ↔ chữ
                 ▼
Language-guided query selection: chọn 900 vị trí ảnh khớp chữ nhất
                 ▼
Cross-modality decoder (6 lớp) → mỗi query: box (cx, cy, w, h) + điểm khớp với token "food"
                 ▼
──────────── Pipeline foodbox (code nhóm) ────────────
  1. Giữ box điểm ≥ 0,05, tối đa 100 box/ảnh (kết quả thô, lưu theo đợt mỗi 50 ảnh)
  2. NMS (IoU 0,5) bỏ box trùng; bỏ box < 0,2% diện tích ảnh
  3. Ngưỡng: box ≥ 0,35; box lớn nhất = món theo tên thư mục; box còn lại = food_other nếu điểm ≥ 0,45
  4. Xuất: labels/<món>/*.txt (YOLO), visualized/ (mỗi box một màu), crops/<món>/<ảnh>_<k>.jpg (cắt đúng box, từ ảnh gốc),
     classes.txt, data.yaml, train.txt/val.txt (80/20), report.csv, failed.csv

Chạy song song 2 GPU T4 trên Kaggle: mỗi GPU một nửa số ảnh.

# Tiền xử lý dữ liệu và chuẩn hoá
-------------------------------------------------------------------------------------------

## Mô tả tiền xử lý dữ liệu và chuẩn hoá bằng diễn giải

1. Dò dữ liệu: tự tìm mọi thư mục dạng <tên_món>/*.jpg (mỗi bản upload có cấu trúc khác nhau); gộp train/valid nếu có.
2. Chọn tập con: 10 món × 20 ảnh, chọn ngẫu nhiên với seed 0 (chạy lại ra cùng ảnh).
3. Đọc ảnh: xoay theo tag EXIF (giống cách YOLO và X-AnyLabeling đọc ảnh), đổi sang RGB. Ảnh gốc không bị sửa.
4. Câu chữ: "food." (viết thường, kết thúc bằng dấu chấm, theo yêu cầu của Grounding DINO).
5. Processor của Grounding DINO tự resize (cạnh ngắn ~800) và chuẩn hóa theo mean/std ImageNet.
6. Box thật UEC (đánh giá): gộp bb_info.txt của mọi thư mục món (ảnh nhiều món nằm ở nhiều thư mục), kẹp box vào trong
   ảnh, chuyển sang YOLO (class_id x_center y_center width height, chuẩn hoá 0–1).

## Mô tả tiền xử lý bằng Code

```python
# foodbox/data.py
def load_image(path):
    """Mở ảnh RGB, xoay theo EXIF (giống cv2.imread mà YOLO/Ultralytics và X-AnyLabeling dùng)."""
    with Image.open(path) as im:
        return ImageOps.exif_transpose(im).convert("RGB")

# foodbox/labels.py
def xyxy_to_yolo(box, w, h):
    x1, y1, x2, y2 = box
    return ((x1 + x2) / 2 / w, (y1 + y2) / 2 / h, (x2 - x1) / w, (y2 - y1) / h)
```


# Định nghĩa mô hình
-------------------------------------------------------------------------------------------

- Grounding DINO bản base (Swin-B + BERT-base), trọng số `IDEA-Research/grounding-dino-base` (license Apache-2.0),
  tải tự động từ HuggingFace (~900 MB). Không sửa kiến trúc, không fine-tune.
- Gọi qua `transformers` (`AutoModelForZeroShotObjectDetection`). Lấy box có điểm ≥ 0,05 (giữ nhiều để còn tính AP), lọc
  ngưỡng thật ở bước hậu xử lý.
- Khi thử prompt khác (bước 03), điểm của box = điểm cao nhất trên các token của prompt chính.

```python
# foodbox/detectors.py (rút gọn)
class GroundingDINO:
    def __init__(self, prompts=("food",), device="cuda", low_thr=0.05, max_det=100):
        mid = "IDEA-Research/grounding-dino-base"
        self.processor = AutoProcessor.from_pretrained(mid)
        self.model = AutoModelForZeroShotObjectDetection.from_pretrained(mid).to(device).eval()
        self.text = " ".join(p.strip().lower().rstrip(".") + "." for p in prompts)   # "food."
        ...

    @torch.no_grad()
    def predict(self, img):
        inputs = self.processor(images=img, text=self.text, return_tensors="pt").to(self.device)
        out = self.model(**inputs)
        r = self.processor.post_process_grounded_object_detection(
            out, inputs["input_ids"], threshold=self.low_thr, text_threshold=self.low_thr,
            target_sizes=[(img.height, img.width)])[0]
        return r["boxes"].cpu().numpy(), r["scores"].cpu().numpy()     # box pixel (x1, y1, x2, y2), điểm
```


# Quá trình huấn luyện mô hình
-------------------------------------------------------------------------------------------

Không huấn luyện (zero-shot). Các bước thay cho huấn luyện:
  1. Chọn model: so sánh Grounding DINO, OWLv2, YOLO-World (± SAM 2.1) trên 200 ảnh UEC có box thật.
  2. Chọn hậu xử lý: phát hiện 2 bộ lọc làm hỏng kết quả (lọc box gần cả ảnh, lọc box chứa box khác), bỏ đi thì AP@0.5
     tăng 0,62 → 0,73.
  3. Chọn ngưỡng: 0,45 (theo UEC) quá chặt với Food-101 (chỉ 78,5% ảnh có box) → hạ 0,35 cho món chính, giữ 0,45 cho
     food_other → 97% ảnh có box, không tăng box sai.
  4. Thử prompt: "food" / tên món / thêm "plate. bowl. cup. tray." → giữ "food".

# Nhận xét rút ra kết luận
-------------------------------------------------------------------------------------------

### 1️⃣ Phần Nhận Xét

✅ **Hiệu suất tổng thể của mô hình**
- Ảnh 1 món: tốt, tìm được 90% món; trên Food-101 box món chính đúng 94,8%.
- Ảnh khay nhiều món: còn yếu, chỉ tìm được 68% món; quy tắc "box lớn nhất = món chính" chỉ đúng 38%.
- Box ôm phần thức ăn chứ không ôm cả đĩa. Đây là điều đề bài cần, nhưng làm điểm IoU so với box thật UEC thấp hơn.

✅ **Tính ổn định của mô hình**
- Không có yếu tố ngẫu nhiên khi chạy (không huấn luyện): chạy lại ra cùng kết quả (bước 03 chạy lại "food" ra đúng 0,732).
- Lỗi lặp lại ở món gồm nhiều miếng rời (sushi, falafel, french toast): lúc ôm cả đĩa, lúc ôm từng miếng.

✅ **Thời gian chạy**
- 0,58 s/ảnh trên T4, 2 GPU song song: 1.500 ảnh (dataset dự kiến) khoảng 8 phút. CPU: ~11 s/ảnh.

✅ **Overfitting / Underfitting**
- Không áp dụng (không huấn luyện). Ngưỡng chọn trên UEC lệch với Food-101 (0,45 → 0,35), nên khi có dataset thật cần
  kiểm tra lại ngưỡng trên vài chục ảnh.

Ví dụ nhận xét:
> "Grounding DINO zero-shot với prompt 'food' đạt AP@0.5 0,73 trên 200 ảnh UECFOOD-256, ngang YOLO-World và hơn hẳn OWLv2.
> Với ảnh 1 món, pipeline tìm được 90% món và box món chính đúng 95% khi chấm tay trên Food-101; box ôm phần thức ăn chứ
> không ôm cả đĩa. Với ảnh khay nhiều món, pipeline mới tìm được 68% món và hay chọn sai món chính."

---

### 2️⃣ Phần Kết Luận

1️⃣ **Mô hình có phù hợp với bài toán không?**
Có, cho ảnh 1 món (phần lớn dataset dự kiến: mỗi món một thư mục): dùng làm nhãn nháp rồi sửa tay các ảnh bị đánh dấu.
Chưa phù hợp cho ảnh khay nhiều món nếu cần biết box nào là món nào.

2️⃣ **Có cần cải thiện không? Nếu có, cách nào?**
- Ảnh nhiều món: chọn món chính bằng prompt tên món thay vì box lớn nhất.
- Ảnh không có box: thử lại bằng prompt tên món (thử trên dữ liệu có sẵn: cứu được 5/6 ảnh, cả 5 box đúng; chưa đưa vào pipeline).
- Món nhiều miếng: gộp các box con nằm trong box món chính.
- Tốc độ: train YOLO trên nhãn tự động (đã có sẵn data.yaml) để có model nhỏ, nhanh của nhóm.

3️⃣ **Hướng nghiên cứu tiếp theo?**
- Chạy trên dataset thật của nhóm khi có; sửa tay bằng X-AnyLabeling; train YOLO nhận diện món (YOLOv9/v10/v11).
- Ghép với phần nhận diện món và tính dinh dưỡng (kế hoạch tháng 12).

Ví dụ kết luận:
> "Luồng auto bounding box dựa trên Grounding DINO chạy được bằng một lệnh trên Kaggle, xuất sẵn nhãn YOLO, ảnh vẽ box và
> ảnh cắt từng món, đủ tốt cho ảnh 1 món (90% món được tìm thấy). Ảnh khay nhiều món còn yếu và là hướng cải thiện tiếp theo,
> cùng với việc train YOLO trên nhãn tự động để có model nhanh cho web app."

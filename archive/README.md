# Lưu trữ (chỉ đọc)

Thí nghiệm cũ, giữ lại để tham khảo; không dùng trong code hiện tại.

- `nutrition5k_distributed_project/`: các thí nghiệm Nutrition5k trước khi có task TiMePReSt (Exp 1–5: ResNet18/50, RGB-D,
  1 GPU so với 2 GPU). `n5k/PLAN.md` mục 3 và mục 5 dùng số liệu tốc độ và split cố định của các thí nghiệm này
  (split đã chép sang `n5k/splits/`).
